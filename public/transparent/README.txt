라때 누끼(투명 배경) 에셋

파일 이름 규칙
- *-transparent-*        밝은 배경용 (흰색·크림 화면)
- *-ondark-*             어두운 배경용 (진한 갈색 선과 글자를 크림색으로 바꾼 버전)
- *-notext-*             로딩 문구 없는 버전 (앱에서 문구를 직접 띄울 때)
- *-trimmed.png          여백을 잘라낸 아이콘
- *-still.png            로딩 애니메이션의 정지 화면

형식
- 아이콘: PNG 1024 / 512 / 192, SVG
- 로딩: 애니메이션 WebP(추천, 투명 지원), APNG(.png), 정지 PNG
  GIF는 투명 가장자리가 계단처럼 깨져서 투명 버전은 만들지 않았습니다.
